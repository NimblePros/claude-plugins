# presenting

Resources and guidance for creating multimedia presentations — slide decks, live demos,
recorded videos, and conference talks.

```bash
claude plugin marketplace add NimblePros/claude-plugins
claude plugin install presenting@nimblepros
```

## Skills

| Skill | What it covers |
|---|---|
| `multimedia-presentations` | Planning a presentation, choosing the right format, structuring slides, preparing demos, recording videos, and avoiding common delivery mistakes. |

## Roadmap

Candidates for this plugin as content is written: `demo-rehearsal`, `speaker-notes`,
`screencast-production`, and a `presentation-coach` agent.
